# Kinde Provider

- [Kinde docs](https://docs.kinde.com/)

## Setup

### Callback URL

```
https://example.com/api/auth/callback/kinde
```

### Environment Variables

```
AUTH_KINDE_ID
AUTH_KINDE_SECRET
AUTH_KINDE_ISSUER
```

### Configuration

> **Note:** `issuer` is required — the provider has no default. It is your Kinde domain, e.g. `https://<your_subdomain>.kinde.com`. Set it as `AUTH_KINDE_ISSUER`.

<Code.Next>

```ts filename="./auth.ts"
import NextAuth from "next-auth"
import Kinde from "next-auth/providers/kinde"

export const { handlers, auth, signIn, signOut } = NextAuth({
  providers: [
    Kinde({
      issuer: process.env.AUTH_KINDE_ISSUER,
    }),
  ],
})
```

## Notes

The Kinde provider comes with a [default configuration](https://github.com/nextauthjs/next-auth/blob/main/packages/core/src/providers/kinde.ts). To override the defaults for your use case, check out [customizing a built-in OAuth provider](https://authjs.dev/guides/providers/custom-provider).
